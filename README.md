# Doğum günü sitesi

Kurulum gerektirmez. `index.html` dosyasını tarayıcıda açarak önizleyebilirsin.

## Kişiselleştirme

`index.html` içindeki `İyi ki doğdun!` başlığını, `birthday-message` bölümündeki mesajı ve `signature` bölümündeki imzayı değiştirebilirsin.

## GitHub Pages ile paylaşma

1. GitHub'da yeni bir **public** repository oluştur.
2. `index.html` dosyasını (istersen `README.md` ile birlikte) repository'nin ana dizinine yükle ve commit et.
3. Repository'de **Settings → Pages → Build and deployment** bölümüne gir.
4. **Source** olarak **Deploy from a branch**, **Branch** olarak **main** ve **/(root)** seçip kaydet.
5. GitHub Pages'in verdiği `https://KULLANICI-ADI.github.io/REPO-ADI/` bağlantısını paylaş.

Site açılması birkaç dakika sürebilir.
